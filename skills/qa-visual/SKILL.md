# qa-visual — Visual Regression Testing

Performs automated visual regression verification with intelligent anti-aliasing masking, dynamic content suppression, and responsive viewport matrices.

## 1. Capabilities
- Playwright screenshot diffing (`toHaveScreenshot`).
- Masking dynamic timestamps, avatars, and animated elements.
- Cross-browser rendering validation (Chromium, Firefox, WebKit).
- Dark/light mode theme snapshot verification.
