# qa-accessibility — Accessibility & WCAG 2.1 AA Auditing

Embeds continuous accessibility testing using Axe Core and Playwright to guarantee compliance with WCAG 2.1 AA standards.

## 1. Core Focus Areas
- Automated Axe scanning across all public and authenticated routes.
- Zero tolerance for critical accessibility violations in CI release gates.
- Keyboard navigation verification (Tab, Enter, Escape modal focus traps).
- Screen reader accessibility: accessible roles, labels, and ARIA live regions.
