# qa-contract — Consumer-Driven Contract Testing

Validates microservice contracts and API interfaces using Pact, OpenAPI specifications, and JSON Schemas to detect breaking integration changes before deployment.

## 1. Capabilities
- Automated verification of OpenAPI 3.x contract definitions against server responses.
- Prevention of field renames, type mutations, and unexpected nullability.
- Breaking change detection during pull request review.
