# qa-mobile — Mobile Testing & Appium Automation

Supports mobile web and native application testing across iOS and Android simulators and real device clouds (BrowserStack/SauceLabs) using Appium and Playwright mobile emulation.

## 1. Capabilities
- Responsive viewport and touch gesture emulation (tap, swipe, pinch).
- Device matrices covering standard iOS (Safari) and Android (Chrome) form factors.
- Network throttling simulation (3G, 4G, offline mode).
