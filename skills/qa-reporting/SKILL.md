# qa-reporting — Multi-Audience Quality Reporting

Generates tailored, high-signal quality reports targeting four distinct stakeholder audiences:

## 1. The Four Audiences
1. **Engineering**: Failing tests, stack traces, exact code diffs, root-cause hypotheses, and fix recommendations.
2. **QA & SDETs**: Coverage breakdown, flake scores, regression health, test quality scorecards, test debt tracker.
3. **Engineering Leadership**: Release confidence score, critical business risks, historical defect trends, quality debt index.
4. **Executive / Product**: Release readiness verdict, blockers, customer business-risk exposure.

## 2. Supported Formats
JUnit XML, Allure, Markdown summaries for GitHub PR comments, Slack/Teams webhooks, and JSON feeds.
