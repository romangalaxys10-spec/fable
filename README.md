## ⚡ Executive Overview

**Fable** and **qaforge** transform AI coding agents from passive script writers into an **autonomous, evidence-driven, elite engineering and QA organization**. 

Rather than relying on brittle prompts or expensive fine-tuning on static trivia, the system provides:
1. **A Real-Time Experience Layer**: Retrieves prior verified agent session traces from 5+ Hugging Face datasets with on-device relevance triage (`Laya MLX`) and neural transcript compression (`Headroom`).
2. **qaforge QA Operating System**: A hybrid two-layer architecture (28 structured skills + 10 executable platform packages) featuring 8-factor mathematical risk scoring, AST change impact analysis, 12-category failure clustering, confidence-tiered self-healing, and a 21-command universal CLI.
3. **Offensive Security & Ground Truth**: Autonomous DAST penetration testing with sandbox Proof-of-Concept exploit validation (`Strix`), Cloudflare 6-phase fleet security auditing, and double-blind bug reproduction (`Reverify`).
4. **Universal Token Efficiency Protocol (v3.3.0)**: Slashes context consumption from ~280k to ~35k tokens (**8x / 87.5% reduction**) through AST-first file reading, Dynamic Tool Output Compression (DTOC), and 5-phase context budgeting.
5. **Zero-Config Autopilot**: Operates 100% out of the box with **zero required API keys, external tokens, or cloud registrations**.

## 🛡️ qaforge: AI-Native QA Operating System

`qaforge` upgrades coding agents from reciting general testing advice to operating a complete, multi-tiered test infrastructure.

### The Two-Layer Architecture

#### Layer A — Agent Skills (`skills/*/SKILL.md`)
28 modular, self-contained skills written strictly according to enterprise QA contracts (Purpose, Activation Triggers, Inputs, Preconditions, Decision Rules, 8 Heuristics, Anti-Patterns, Evidence Schemas, Safety Constraints, Verification Checklists):

| Category | Skills Included | Functional Mandate |
| :--- | :--- | :--- |
| **Gateways & Flow** | `qa-enterprise`, `qa-orchestrator` | All-in-one entry gateway and 12-stage lifecycle intent routing. |
| **Flagship Differentiators** | `qa-llm-testing`, `qa-agent-evaluation` | 10-dimension LLM evaluation (faithfulness, hallucination, safety, schema drift) and autonomous coding agent benchmarking. |
| **Killer Capabilities** | `qa-impact-analysis`, `qa-risk-analysis`, `qa-failure-triage`, `qa-test-healing` | AST change impact selection, 8-factor mathematical risk engine, 12-category triage, and confidence-tiered self-healing. |
| **Core Disciplines** | `qa-discovery`, `qa-requirements`, `qa-test-strategy`, `qa-test-generation`, `qa-test-review`, `qa-test-execution`, `qa-flake-detection`, `qa-coverage-analysis` | Full architectural lifecycle: topology discovery, pyramid modeling, spec generation, flake isolation, and coverage verification. |
| **Specialized Testing** | `qa-visual`, `qa-accessibility`, `qa-api`, `qa-contract`, `qa-security`, `qa-performance`, `qa-mobile`, `qa-data` | Visual regression, Axe a11y, REST/GraphQL, Pact contracts, OWASP ZAP, k6 load testing, Appium, and test data fixtures. |
| **Release & Governance** | `qa-release-gate`, `qa-reporting`, `qa-observability`, `qa-governance` | 15 Golden Rules invariant checks, Allure/JUnit/Slack reports, and OpenTelemetry instrumentation. |
| **Offensive & Ground Truth** | `reverify`, `stop-slop`, `strix-pentest`, `cloudflare-security-audit` | Ground truth verification, anti-slop craft scoring, autonomous DAST penetration testing, and 6-phase edge security audits. |

---

#### Layer B — Execution Platform (`packages/*`)

1. **`packages/core/`**:
   - **QA Context Model (`context.ts`)**: Zod-validated shared state model tracking application profile, risk, requirements, changed files, coverage, known flakes, and defect history.
   - **8-Factor Risk Engine (`risk.ts`)**: Formula normalizing business criticality, change surface, defect history, complexity, integration depth, user impact, security sensitivity, and data sensitivity ($0-100$).
   - **AST Change Impact Engine (`impact.ts`)**: Maps modified files and symbols directly to affected test subsets (unit, integration, e2e).
   - **15 Golden Rules (`golden-rules.ts`)**: Non-negotiable quality invariants (zero arbitrary sleeps, preserve assertion strength, no regression masking, parallel isolation).
   - **Safe Automation Policy (`safe-automation.ts`)**: Enforces tri-level permissioning (`READ-ONLY`, `LOW-RISK WRITE`, `HIGH-RISK`).
   - **12-Stage Lifecycle Engine (`lifecycle.ts`, `orchestrator.ts`)**: Intelligent routing across CSS, payment, database migration, and auth changes.
   - **Zero-Config Bypass (`zero-config.ts`)**: Transparent offline simulation fallback proxy.

2. **`packages/agents/` (8 Specialized Sub-Agents)**:
   - `DiscoveryAgent`: Detects languages, frameworks, test topology, and CI systems.
   - `RequirementsRiskAgent`: Extracts acceptance criteria and computes requirement risk profiles.
   - `TestStrategyAgent`: Calculates pyramid distributions (unit 70%, integration 20%, e2e 10%) and penalizes unnecessary E2E overhead.
   - `TestGeneratorAgent`: Generates enterprise tests across 8 heuristics (Positive, Negative, Boundary, State, Concurrency, Time, Security, Resilience).
   - `ExecutionAgent`: Coordinates isolated test runs across runners.
   - `TriageAgent`: 12-category failure triage and cascade clustering.
   - `SelfHealingAgent`: Synthesizes confidence-tiered DOM/locator patches without loosening assertions.
   - `QualityGovernanceAgent`: Evaluates release gates and checks hard blockers.

3. **`packages/runners/` (5 Test Runners)**:
   - Adapters for `Playwright`, `pytest`, `k6` performance, `OWASP ZAP` baseline security, and `Appium` native mobile.

4. **`packages/healing/`**:
   - Confidence-tiered self-healing:
     - **HIGH**: Safe auto-patching of renamed test IDs or semantic locators.
     - **MEDIUM**: Proposes PR diff for engineer review.
     - **LOW**: Flags assertion or logic failure for human investigation (never masks real regressions).

5. **`packages/data/`**:
   - Test Data Engineering: `SeedGenerator` (linear congruential deterministic RNG), `TestDataFactory`, `UserFixtureBuilder`, `OrderFixtureBuilder`, and PII/token `DataMasker`.

6. **`packages/reporting/`**:
   - Multi-channel enterprise reporting: `generateJUnitXml`, `formatAllureResult`, `formatSlackQualityPayload`, `formatJiraDefectPayload`, `formatGitHubStepSummary`, `formatGitLabCodeQuality`, and **Quality Traceability Matrix (`qa matrix`)**.

7. **`packages/reasoning/`**:
   - `MultiModelReasoningRouter` enforcing **Deterministic-First, AI-Second** discipline with full explainability records (`input`, `objective`, `evidence`, `output`, `confidence`, `fallback`).

8. **`packages/graph/`**:
   - Bi-directional `QualityGraph` connecting Requirement $\rightarrow$ Feature $\rightarrow$ Code $\rightarrow$ API $\rightarrow$ UI $\rightarrow$ Test $\rightarrow$ Execution $\rightarrow$ Evidence $\rightarrow$ Defect.

9. **`packages/mcp-server/` (11 MCP Tools)**:
   - Model Context Protocol server exposing all tools natively to agent IDEs.

10. **`packages/reverify/`, `packages/stop-slop/`, `packages/strix/`, `packages/security-audit/`**:
    - Dedicated execution packages for ground truth verification, anti-slop craft scoring, autonomous DAST, and edge audits.

## ⚡ Universal Token Efficiency Protocol (v3.3.0)

Derived from the Pi coding agent, Databricks MemEx, and Marcos Hernanz's 60B-token behavioral agent rules (`skills/token-efficiency/SKILL.md` and `scripts/token_efficiency.py`). Slashes agent context footprint from **~280k to ~35k tokens** (an **8x / 87.5% reduction**).

### The 8 Behavioral Pillars
1. **AST-First File Access**: Never run `cat` or read files $>100$ lines. Use `grep -n` or `sed -n 'start,endp'` to pinpoint lines.
2. **Search Hierarchy**: Literal `grep` $\rightarrow$ Regex `grep` $\rightarrow$ AST-grep $\rightarrow$ Targeted line read.
3. **Dynamic Tool Output Compression (DTOC)**: Strict line caps enforced before context ingest (`ls`: 20, `logs`: 30, `diff`: 100, `config`: 80).
4. **Progressive Disclosure**: Tier 1 (Discover) $\rightarrow$ Tier 2 (Target) $\rightarrow$ Tier 3 (Execute).
5. **6-Field Subagent Scoping**: Strict boundary templates (`Task`, `File`, `Structure`, `Relevant excerpt`, `Constraints`, `Output format`).
6. **Session File Cache**: Eliminates redundant file re-reads across turns.
7. **Context Compaction**: Compact finished phases when context exceeds 80% capacity.
8. **OS Memory Guards**: Node heap capped at 2048M, ZRAM zstd compression.

### 5-Phase Context Budget Allocation

| Phase | Target Token Budget | Permitted Context Scope |
| :--- | :--- | :--- |
| **1. Discovery** | ~4,000 tokens | Directory hierarchy, manifest files, key identifiers |
| **2. Planning** | ~8,000 tokens | Implementation plan and targeted code excerpts only |
| **3. Execution** | ~12,000 tokens | Active contiguous line ranges being edited and errors |
| **4. Verification** | ~4,000 tokens | Test execution status and unified diff summary |
| **5. Summary** | ~2,000 tokens | Final outcome, changed files, and lesson card |
| **TOTAL** | **~30,000 tokens** | **vs. ~280,000 unconstrained baseline (8x savings)** |

```bash
# Calculate 5-phase budget for any task
python3 scripts/token_efficiency.py budget --task "Refactor checkout service"

# Test DTOC compression on verbose terminal logs
python3 scripts/token_efficiency.py compress --input "raw server log..." --type logs

# Generate 6-field scoped subagent prompt
python3 scripts/token_efficiency.py subagent --file "src/payment.ts" --goal "Fix race condition" --lines "40-90"

# Audit proposed file read for AST-first compliance
python3 scripts/token_efficiency.py audit_read --file "src/server.ts" --lines 350
```

## 🔒 Security, Pentesting & Ground Truth

### 1. Reverify: Ground Truth Verification (`2akouwu/reverify`)
Eliminates AI hallucinations by prohibiting the agent from asserting facts independently:
- Claims about codebase state, function signatures, or bug causes are submitted as hypotheses.
- Probed deterministically via disk, AST, or test execution.
- Refuted claims are stored in a persistent `KNOWN_FALSE` registry, permanently blocking the agent from recycling false assumptions.
- **Double-Blind Bug Verification**: Mandatory pre-fix test must fail on unchanged code; post-fix test must pass with zero regressions.

### 2. Stop-Slop: Human Craft Standard (`hardikpandya/stop-slop`)
Enforces authentic, high-density engineering communication and clean UI:
- **8 Banned Patterns**: Throat-clearing openers ("In today's fast-paced digital world..."), formulaic three-part lists, false binary contrasts, buzzwords ("robust solution", "game changer"), and visual clutter (pill buttons, purple glow).
- **50-Point Craft Rubric**: Evaluates Voice (10), Specificity (10), Structure (10), Density (10), and Visual Craft (10). Any score $<35/50$ triggers an automatic rewrite.

### 3. Strix: Autonomous DAST Pentesting (`usestrix/strix`)
Multi-agent offensive security framework covering the OWASP Top 10:
- **Zero False Positives Invariant**: Only reports vulnerabilities if an executable Proof-of-Concept (PoC) exploit succeeds inside an isolated sandbox.
- Generates reproducible cURL commands, attack scripts, CVSS v3.1 scores, and verified remediation diffs.

### 4. Cloudflare 6-Phase Security Audit (`cloudflare/security-audit-skill`)
Transforms agents into fleet-wide security auditors across 6 isolated phases:
1. `Reconnaissance` $\rightarrow$ 2. `Coverage-Led Hunting` $\rightarrow$ 3. `Candidate Validation` $\rightarrow$ 4. `Structured Output` $\rightarrow$ 5. `Independent Verification` $\rightarrow$ 6. `Target-Neutral Report`.
- Audits edge invariants: CSP, HSTS (`max-age=63072000`), `X-Content-Type: nosniff`, CORS origin restriction, and TLS 1.3.
