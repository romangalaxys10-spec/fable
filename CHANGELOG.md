## v0.19.0 — 2026-09-25 — the platform release (10 features)

### Added
- **Semantic search** (`scripts/semantic_search.py`) — embedding-based corpus search (all-MiniLM-L6-v2, local). `build` indexes the corpus, `auto` queries with keyword fallback.
- **Auto-capture hooks** (`hooks/hooks.json` + `scripts/auto_capture.py`) — SessionEnd hook drafts lesson cards into `~/.fable/drafts.jsonl` automatically; review-then-promote keeps quality high.
- **Route learning loop** — `route.py --feedback --engines "a|b" success|fail` records outcomes; engines with ≥70% success get boosted, <30% (3+ samples) downgraded. `record.js` outcomes now feed the loop.
- **MCP server** (`scripts/mcp_server.py`) — stdio MCP exposing `fable_route/search/retrieve/boost/escalate/report` to any MCP client (Cursor, Claude Desktop, …).
- **Cross-device sync** (`scripts/sync_corpus.py`) — `push [--git dir]` / `pull --from` / `status`; dedupe-merging for corpus and append-merging for stats.
- **Token telemetry** (`scripts/telemetry.py`) — Headroom savings, Laya verdicts, gate blocks accumulated in `~/.fable/telemetry.jsonl`; `dashboard` aggregates. boost.py records automatically.
- **Site-health scan** (`scripts/site_health.py`) — one command: security + SEO/GEO scan → immersive report files.
- **SEO/GEO fix packs** (`seoaudit.py --fixpack DIR`) — exact artifacts per finding: JSON-LD, meta tags, FIXPACK.md instructions.
- **Sandbox execution** (`scripts/harness/sandbox.py`) — compile/run installed capabilities inside a no-network Docker container.
- **Laya tune** (`scripts/laya_tune.py`) — builds a fine-tune dataset (positive/negative pairs) from your corpus for the Laya decision model.

### Changed
- Route.py: feedback-aware routing, `--feedback` mode, datetime import.
- audit.py: `.env` lookahead (process.env false positive), `.mimosa` excluded, egress/credential checks scoped to code files, api.github.com allowlisted.
- setup.py: `eval()` removed (int parse).
